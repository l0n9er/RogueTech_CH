# BATTLETECH / RogueTech 简体中文补丁

给 **BATTLETECH**（含全部 DLC）与 **RogueTech** 大型模组包使用的简体中文汉化补丁。

面向已经装好 RogueTech 的玩家：解压、双击 `安装.bat`、重启游戏即可。

> **当前版本：v25**
> 适配 RogueTech 主分支（截至 2026-09）。游戏或 RogueTech 更新后需要重新安装（见下方"重要提醒"）。

---

## 这是什么

一个**文本汉化补丁**，不修改任何游戏机制、数值或平衡性，只替换显示文字。

覆盖范围：

| 内容 | 说明 |
|---|---|
| 翻译总表 | `strings_zh-CN.csv`，61,339 行 / 60,888 键 |
| 机甲 / 战车 / 战甲 | 名称、描述、角色定位（Details / YangsThoughts / StockRole） |
| MechAffinity | 亲和面板的名称与描述 |
| 各模组本地化表 | 战斗、合约、事件、星图等 |
| 装备分类显示名 | 机库与商店的筛选分类 |
| AI 能力与特征 | 驾驶员特质、光环、环境效果说明 |
| 任务目标标题 | 合约中的可见目标 |

术语以 **官方中文术语表**（terms-13908.json，2,952 条）与项目自建术语表为准，
并做过全表一致性归一（如 混战→近战、载具→车辆、驾驶员→机师）。

## 安装

### 前置条件

- 已安装 **BATTLETECH**（Steam 或 GOG 版）与 **RogueTech** 模组包
- Windows + PowerShell 5.1（系统自带）
- **游戏必须完全退出**（游戏运行时会占用模组文件，无法替换）

### 步骤

1. **完全退出游戏**（包括启动器 RogueLauncher）

2. **解压**本补丁到任意目录（路径不要含特殊符号，中文路径可以）

3. **双击 `安装.bat`**

   脚本会自动完成 9 个步骤。安装耗时约 **3~4 分钟**，请等它跑完再关窗口。

4. **重新启动游戏**

   （模组数据只在启动时读取，装完必须重启才会生效）

### 关于游戏路径

安装脚本会**自动识别**游戏目录，依次尝试：

1. RogueTech 启动器的配置文件
2. Steam 注册表登记的库目录
3. 各磁盘下的常见安装位置

如果自动识别失败，可以手动指定：

```bat
powershell -File "工具\安装.ps1" -gameRoot "D:\Steam\steamapps\common\BATTLETECH"
```

（把路径换成你自己的游戏根目录，即 `BattleTech.exe` 所在的那一层）

### 安装脚本做了什么

1. 写入翻译总表
2. 写入 MechAffinity 亲和数据
3. 替换 MechAffinity 界面标签
4. 清理遗留的 `.zhbak` 备份文件
5. 汉化数据字段（Details / YangsThoughts / StockRole）
6. 汉化装备分类显示名
7. 清理控制字符与标点空格
8. 术语归一化与格式修复
9. 校验

**安全设计：**

- 覆盖任何文件前，都会备份到 `backup\<时间戳>\`
- 检测到游戏正在运行时**直接报错退出**，不会写坏文件
- 脚本**可重复执行**，不会重复写入或破坏内容

## 重要提醒

### 游戏或 RogueTech 更新后，汉化会被重置

**这是正常现象**，不是补丁有问题。

原因：RogueTech 更新时会用官方英文原版文件覆盖模组数据，汉化自然就没
了。解决办法很简单：

> **重新运行一次 `安装.bat` 即可恢复。**

### 建议的更新流程

```
1. 用 RogueLauncher 更新 RogueTech
2. 完全退出游戏
3. 重新运行 安装.bat
4. 启动游戏
```

### 首次安装后建议重启游戏两次

如果你之前装过其它汉化或手动改过文件，第一次启动可能仍显示旧文本
（模组缓存）。再重启一次即可。若仍有异常，先完全删除
`<游戏目录>\Mods\.modtek\Cache` 目录再启动，让 ModTek 重建缓存。

## 回滚（卸载汉化）

安装脚本会把被覆盖的原文件备份到：

```
backup\<时间戳>\
```

备份文件名 = 原路径把反斜杠换成下划线。例如：

```
Mods_Core_RogueTechCore_Localization.json
```

对应 `<游戏目录>\Mods\Core\RogueTechCore\Localization.json`。

**回滚方法**：把备份文件按上述规则还原回原位，或直接用 RogueLauncher
的"修复/重装模组"功能还原，然后重新安装汉化。

## 已知未汉化的部分

以下内容**无法**通过本补丁汉化，属于技术限制：

- **插件 DLL 里硬编码的文字**（如机库界面的 `Carry Weight`、`Required Hardpoint`、
  `Categories:` 等面板标签）。这类文字不查翻译总表，需要逐个改二进制。
- **运行时动态拼接的文本**（如把两个数值拼成一句话）。
- 少量**隐藏占位符**（`Hidden TimerObjective` 之类），玩家正常情况下看不到。

## 常见问题

**Q：装完后部分文字还是英文？**

A：按顺序排查：① 确认装完后**重启过游戏**；② 检查是否装了其它会覆盖
文本的汉化模组；③ 删除 `<游戏目录>\Mods\.modtek\Cache` 后重启。

**Q：某些汉字显示成方框？**

A：游戏主字体缺少个别汉字的字形。本补丁已通过替换生僻字规避了已知的
109 个缺字，如果你仍看到方框，请提交截图和出现位置。

**Q：安装脚本报"检测到游戏正在运行"？**

A：完全退出游戏（含 RogueLauncher、Steam 的启动进程），再重新运行。

**Q：安装脚本说"找不到游戏目录"？**

A：用 `-gameRoot` 参数手动指定，见上方"关于游戏路径"。

**Q：可以用 MO/ModTek 的模组形式加载吗？**

A：可以。把 `可选-模组形式\CustomLocalization-ZH-CN` 整个文件夹复制到
`<游戏目录>\Mods\Options\Localization\` 即可（内容与主表一致）。
注意这种方式会**优先于**游戏目录内的总表，将来社区更新总表时可能被它挡住。

## 目录结构

```
strings_zh-CN.csv                  翻译总表（游戏真正读取的文件）
安装.bat                          一键安装
说明.txt                          简要说明
文件清单.txt                       完整文件列表
工具\                             安装脚本（一般无需手动运行）
  ├─ 安装.ps1                     主安装脚本
  ├─ find-game.ps1                游戏目录自动探测
  ├─ dict-all.tsv                 翻译词典
  ├─ fold-apply.ps1               数据字段汉化
  ├─ apply-category-zh.ps1        装备分类显示名汉化
  ├─ fix-ctl.ps1                  修复控制字符
  ├─ cleanup.ps1                  清理标点多余空格
  ├─ apply-norm.ps1               术语归一化与格式修复
  ├─ norm-csv.ps1                 规范化总表标点
  └─ qa-check.ps1                 汉化质量自检
Mods\                             已汉化的模组数据
RtCache\                          启动器缓存副本
可选-模组形式\                     把汉化做成 ModTek 模组（可选）
```
